# GDScript Developer Skill

This skill provides functionalities for developing games using GDScript in the Godot Engine. It includes features such as code generation, debugging assistance, and best practices for GDScript development.

## Instructions

### Step 0: Tasks to do regularly during the process

### Step 1: Understanding GDScript
- Familiarize yourself with the syntax and features of GDScript, the scripting language used in the Godot Engine. This includes understanding variables, functions, classes, and the Godot API.
- Read [syntax and features page](references/syntax-and-features.md) for a comprehensive overview of GDScript syntax and features.

### Step 2: Setting Up Your Development Environment - skip if already set up
- Make sure the Godot Engine is installed on your computer. You can download it from the official website - prompt the user to download and install Godot Engine if they haven't already.
- Set up a new project in Godot and create a basic scene to start working on your game.

### Step 3: Planning Your Game - skip if already planned
- Before diving into coding, take some time to plan out your game. This includes deciding on the game mechanics, designing the levels, and outlining the overall structure of your game. 
- Create a design document to outline your game's concept, mechanics, and features.

### Step 4: Implementing Core Features - POC - skip if already implemented
- Start by implementing the core features of your game. This may include player movement, basic interactions, and any essential game mechanics - specified in your design document.
- Use the code generation feature to create boilerplate code for common game components such as player controllers, enemy AI, and UI elements. This can save you time and help you get started quickly.
- When POC is done, test the game to ensure that the core features are working as expected. Use the debugging assistance feature to identify and fix any issues that arise during development.

### Step 5: Feature Development
- Develop bitesized specific features based on the design document. This may include adding new mechanics, creating levels, and enhancing the overall gameplay experience.
- Use the [best practices guidelines](references/best-practices.md) to ensure that your code is clean, efficient, and maintainable
- Regularly test your game to catch any bugs or issues early on in the development process.

## Features
- **Code Generation**: Automatically generate boilerplate code for common game components such as player controllers
- **Debugging Assistance**: Provide tips and tools for debugging GDScript code effectively.
- **Best Practices**: Offer guidelines and best practices for writing clean and efficient GDScript code.
- **Integration with Godot Engine**: Seamlessly integrate with the Godot Engine to enhance the development workflow.
